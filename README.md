# 📚 مكتبتي

موقع عربي (RTL) لإدارة مكتبتك الشخصية — HTML + CSS + JavaScript فقط، بدون خادم أو قاعدة بيانات.

## المزايا
- واجهة عربية متجاوبة بخط **IBM Plex Sans Arabic** وألوان الأخضر الداكن والعاجي
- إحصائيات: إجمالي الكتب / أقرأ حاليًا / مكتملة / لم أبدأها
- بطاقات كتب: العنوان، المؤلف، التصنيف، حالة القراءة، الصفحات، السنة، التقييم، ملاحظات
- إضافة / تعديل / حذف مع نافذة تأكيد ورسائل نجاح (Toast)
- بحث فوري + تصفية حسب التصنيف والحالة + ترتيب
- تغيير سريع لحالة الكتاب من البطاقة نفسها
- حفظ تلقائي في `localStorage` + بيانات تجريبية عند أول تشغيل

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8000
# ثم افتح: http://localhost:8000
```

## النشر على GitHub Pages
1. ارفع الملفات (`index.html`, `styles.css`, `app.js`) إلى مستودع GitHub.
2. من **Settings → Pages** اختر النشر من الفرع `main` والمجلد `/ (root)`.
3. سيعمل الموقع فورًا بدون أي إعداد إضافي.
